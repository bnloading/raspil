# Сайтты тексеру — 09.09.2026

## Өзгерістер

- Журналдың телефон карточкасында және кестесінде «Распилға жіберу» мәтіні анық көрсетіледі. Прогресс бағаны жасырылса, батырма әрекеттер бағанында қалады.
- Төлем тіркеу автоматты түрде қоймадан материал алмайды: өндіріске жіберу бөлек батырмамен орындалады. Қарызға жіберу мүмкіндігі және аудит сақталған.
- Қоймадан алу мен распил кезегіне ауысу бір Firestore транзакциясында орындалады. Төлем мен тапсырыс күйі сервердегі соңғы дерекпен тексеріледі.
- Қайталап жіберу қойманы, кезек тарихын қайталамайды. Басталған тапсырысты ескі экраннан кезекке кері қайтару бұғатталған.
- Қоймаға қайтаруда транзакцияның оқу/жазу реті түзетілді. Қайтаруды қайталау қорды екі рет көбейтпейді; қалған жолдардың есебі сақталады.
- Төленген соманы енгізгенде Escape өзгерісті төлем ретінде сақтамайды.
- Телефондағы жалақы, есеп, қарыз және KPI сандарының өлшемі реттелді. Үлкен сомалар қиылмай толық көрсетіледі. Журнал карточкалары мен батырмаларының шағын экранға бейімделуі жақсартылды.
- CustomerDebt және ManagerCashbox ішіндегі React hook lint ескертулері түзетілді.

## Тексерулер

- `npm test`: 41 файл, 664 тест өтті.
- `npm run test:rules`: 3 файл, 141 тест өтті. Firebase demo эмуляторы, нақты security rules қолданылды.
- `npm run build`: өтті.
- `npm run lint`: қате және ескерту жоқ.
- Қосылған регрессиялар: қайталап жіберу; басталған тапсырысты қайта жібермеу; ескірген төлем күйі; қоймаға қайтаруды қайталау; распилшы, ПВХ қызметкері және тапсырысқа байланыстырылған клиенттің оқу рұқсаттары.
- Браузерде `/tests/responsive.html` арқылы нақты CSS және тест деректерімен 320, 375, 390, 768, 1440px экрандар тексерілді. Үлкен сандар қиылмады және бет көлденеңінен тасып шықпады. 375px скриншот визуалды қаралды.

## Тексеру шегі

Браузерде белсенді аккаунт болмағандықтан, авторизацияланған беттердегі толық UI сценарийі орындалмады. Рөлдер арасындағы жұмыс барысы Firebase эмуляторында тексерілді; мобильді дизайн бөлек тест үлгісінде қаралды. Бұл барлық ықтимал қатенің жоқтығына кепілдік емес.

Клиент жеке тапсырысын көру үшін оның аккаунты тапсырыстың `customerId` өрісіне байланыстырылуы тиіс. Журналда телефон арқылы бұрынғы байланыстыру механизмі сақталған.

Build ішінде бұрыннан бар үлкен PDF/OCR бандлдары және OCR mixed import туралы ескертулер қалды. Түзетулер жергілікті жобада; production-ға жарияланған жоқ. Жұмыс басталғанға дейінгі өзгерістер сақталды.
