# ЛДСП жұмысшылары, клиент барысы, мобильді есептер және OCR — 09.09.2026

- Распил және ПВХ: ортақ станция дизайны, кезек/менің жұмысым, төменгі тарих навигациясы; жеке орындалған материалдар және жиынтық лист, лист м², ПВХ метрі.
- Лист м² дайын бөлшек ауданы емес. Негізгі материалда тапсырыс snapshot өлшемі, басқа материалда каталог өлшемі қолданылады; өлшем жоқ болса сан болжанбайды.
- Бірнеше жұмысшы істеген тапсырыста cuttingWorkerIds/pvcWorkerIds сақталады. Ескі жазбалардың қосымша орындаушыларын scripts/backfill-worker-history.mjs толтырады (әдепкісі dry-run, --apply жазуды қосады). Скрипт production-да орындалған жоқ. Ескі негізгі тағайындалған қызметкер тарихы бұрынғы сұраумен сақталады.
- Клиенттің тапсырыс карточкасы және цех барысы: лист/ПВХ/ХДФ, кезең нүктелері, жаңару уақыты. Басқа клиенттердің жеке көлемдері ашылмайды.
- Есептер: мобильді ықшам қаржы карточкасы, апталық диаграмма, 2×2 өндіріс көрсеткіштері, қарыз/төлем жұбы; төлем әдістері таңдалған кезеңмен сүзіледі.
- OCR: браузердегі TrOCR Base / Small, API кілтсіз. Үлкен фотолар шектеледі, бос жол жиектері кесіледі, Base үш beam қолданады. Жүктелген модель кештеледі, бірінші жүктеу интернетті қажет етеді; толық offline PWA кепілдігі берілмейді.
- ORT v4 QDQ граф оңтайландыруы TrOCR merged decoder-мен қате берді. Осы OCR сессиясында graphOptimizationLevel=disabled орнатылып, браузердегі нақты inference тексерілді: italic қаріптегі `600 x 450 2` → `600 X 450 2`. Бұл нақты қолжазба дәлдігінің benchmark-і емес; нәтиже пайдаланушы түзететін кестеден кейін ғана импортталады.

Тексеру: TypeScript, ESLint және production build өтті; 667 unit тест, 143 emulator/rules тест өтті. 375px және 320px iframe көріністері нақты React компоненттерімен визуалды қаралды: worker/customer/reports body.scrollWidth == body.clientWidth. Толық авторизацияланған production UI сценарийі орындалмады. Үлкен OCR/PDF бандлдары туралы Vite ескертуі қалды.

Жариялау: Firestore ережелерін frontend-пен бірге шығару керек; ескі қосымша қызметкерлер тарихы үшін backfill скриптін қолдану керек. Production-ға жарияланған жоқ.

Дереккөздер: [TrOCR Base ONNX](https://huggingface.co/Xenova/trocr-base-handwritten), [Transformers.js](https://huggingface.co/docs/transformers.js/index), [ORT QDQ үйлесім мәселесі](https://github.com/huggingface/transformers.js/issues/1637).
